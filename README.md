# Intune-Device-Management-Lab
Microsoft Intune Device Management and Security Project using Intune, Entra ID, BitLocker, Conditional Access, Compliance Policies, and Application Deployment.

# Device Management & Security using Microsoft Intune

## Project Objective

Manage company laptops and mobile devices using Microsoft Intune to improve security, compliance, and centralized administration.

---

## Technologies Used

- Microsoft Intune
- Microsoft Entra ID
- Windows 11
- Android Devices
- BitLocker
- Conditional Access
- Microsoft Defender

---

## Project Tasks

### 1. Device Enrollment

- Enrolled Windows devices into Microsoft Intune.
- Verified successful device registration.

### 2. Compliance Policies

- Configured compliance policies.
- Required password protection.
- Enforced device security settings.

### 3. Configuration Profiles

- Created device configuration profiles.
- Applied security settings to managed devices.

### 4. Application Deployment

- Deployed applications through Intune.
- Monitored installation status.

### 5. BitLocker Management

- Enabled BitLocker encryption.
- Managed recovery keys.

### 6. Conditional Access

- Configured Conditional Access policies.
- Restricted access to compliant devices only.

### 7. Monitoring and Reporting

- Monitored device compliance.
- Reviewed security and deployment reports.
